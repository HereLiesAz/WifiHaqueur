### `build.gradle.kts`

This is the top-level build file for the project. It defines the build configurations that are common to all sub-projects/modules, such as the Android Gradle Plugin version and the Kotlin Android plugin version.

---

### `settings.gradle.kts`

This file defines the project structure and includes the sub-projects/modules that are part of the project. It also configures the repository locations for plugin and dependency resolution.

This is the build file for the `app` module. It defines the dependencies and build configurations specific to the main application module. This includes the Android application plugin, Kotlin Android plugin, and Compose options. It also specifies the application ID, SDK versions, and dependencies.

This file contains ProGuard rules for the `app` module. ProGuard is a tool that shrinks, optimizes, and obfuscates code. This file specifies which classes and methods should be kept during the optimization process.

### `gradlew`

This is the Gradle wrapper script for POSIX-compliant systems (Linux and macOS). It allows developers to run Gradle tasks without having to install Gradle on their system. The script automatically downloads and uses the version of Gradle specified in the `gradle-wrapper.properties` file.

---

### `gradlew.bat`

This is the Gradle wrapper script for Windows. It serves the same purpose as the `gradlew` script, but it is designed to be run in the Windows command prompt.

---

### `gradle/wrapper/gradle-wrapper.properties`

This file configures the Gradle wrapper. It specifies the version of Gradle to be used, the download URL for the Gradle distribution, and other settings related to the wrapper.

---

### `app/src/main/AndroidManifest.xml`

This is the Android Manifest file for the `app` module. It declares the fundamental components of the application, such as its activities, and defines the permissions it requires to function. This file specifies that `MainActivity` is the main entry point of the application and declares other activities like `InstructionsActivity`. It also lists permissions related to Wi-Fi, network state, and location access.

---

### `app/src/main/java/com/hereliesaz/wifihaqueur/MainActivity.kt`

This is the main activity of the application. It is responsible for setting up the user interface using Jetpack Compose and handling user interactions. It requests necessary permissions, such as location for Wi-Fi scanning, and manages the main screen layout, including the navigation rail, scan results, and log view.

---

### `app/src/main/java/com/hereliesaz/wifihaqueur/MainViewModel.kt`

This is the ViewModel for the main screen. It is responsible for managing the application's business logic, state, and data. It handles Wi-Fi scanning, network selection, and the brute-force attack logic. It also manages the password dictionaries and the log messages that are displayed to the user.

---

### `app/src/main/java/com/hereliesaz/wifihaqueur/AppNavRail.kt`

This file defines a composable function that creates the application's navigation rail. The navigation rail provides the primary navigation for the app, with buttons for scanning networks, starting an attack, and selecting a dictionary. It also includes links to the project's GitHub page and a feedback email.

---

### `app/src/main/java/com/hereliesaz/wifihaqueur/DictionarySelectionScreen.kt`

This file defines a composable function that creates the dictionary selection screen. This screen allows the user to choose a password dictionary from a predefined list or to load a custom dictionary file from their device.

---

### `app/src/main/java/com/hereliesaz/wifihaqueur/InstructionsActivity.kt`

This file defines the `InstructionsActivity`, which is responsible for displaying a screen with instructions for the user. The `InstructionsScreen` composable within this file contains text that explains how to use the application, including tips for successful password cracking and contact information.

---

### `app/src/main/java/com/hereliesaz/wifihaqueur/InstructionsClass.kt`
